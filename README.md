
# DineBook

DineBook is a restaurant table reservation system developed for MIS 366.

## Project Description
DineBook allows customers to:
- Create an account and log in.
- Browse available restaurants.
- Select a reservation date and time.
- Choose the number of guests.
- View and manage their reservations.
- Update their personal information.

Administrators can:
- Manage users.
- Manage restaurants.
- Manage reservations.
- Manage restaurant availability.

## Technologies
- ASP.NET Web Forms
- C#
- SQL Server
- ADO.NET
- HTML and CSS
- Session Management

## Database Setup
1. Open SQL Server Management Studio.
2. Open the Database.sql file.
3. Execute the SQL script.
4. Update the connection string in Web.config if necessary.
